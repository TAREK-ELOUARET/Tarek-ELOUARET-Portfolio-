# Tarek Elouaret — One-page Portfolio (FR/EN)

Built from your latest CV.
Includes:
- FR/EN toggle
- Dark/Light mode
- Smooth scrolling navigation + scroll spy
- Sections: Profile, Expertise, Skills, Case studies, Experience, Education, Contact
- CV download: `/public/resume.pdf`

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Edit content
